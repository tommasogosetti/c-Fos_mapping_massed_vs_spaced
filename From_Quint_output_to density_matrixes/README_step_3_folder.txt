"134_SIGLE_HC_FXX_final_for_variability.csv" files: output of the step 2, each file represents one mouse

"matrix_builder.py" script: eliminates 8 further areas deemed uninteresting, bringing the mice to the final number of 126 areas. Furthermore, it generates one matrix for each experimental group, in which each row represent one of the experimental subjects of that group and each column represents a brain area.

"file_dei_gruppi" subfolder: output of the aforementioned script, it contains 5 "XX_per_matrici.csv" matrices, each filled with the densities of every brain area for every subject in a certain experimental group (identified by the first two letters in the filename).
